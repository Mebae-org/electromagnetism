# 第1章 静電場

## 概要

物質中の電荷の動きから導体と不導体の違いを理解し、静止した電荷が作る力、電場、電位を扱います。最後に、電荷を蓄えるコンデンサの電気容量、接続、エネルギーを学びます。

## 学習目標

この章を終えると、次のことができるようになります。

- [ ] 導体と不導体の違いを自由電子の動きと関連させて説明できる。
- [ ] クーロンの法則と重ね合わせの原理から点電荷にはたらく力を求められる。
- [ ] 電場と電位の定義、向き、単位、両者の関係を説明できる。
- [ ] 点電荷および平面・球・平行板が作る電場や電位を計算できる。
- [ ] コンデンサの電気容量、合成容量、蓄積エネルギーを求められる。
