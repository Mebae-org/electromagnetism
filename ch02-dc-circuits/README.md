# 第2章 直流回路

## 概要

電流・電圧・抵抗の意味から始め、オームの法則、抵抗の直列・並列接続、キルヒホッフの法則を用いて直流回路を解析します。電気エネルギーの移動を電力とジュール熱で定量化します。

## 学習目標

この章を終えると、次のことができるようになります。

- [ ] 電流、電圧、抵抗を説明し、オームの法則を適用できる。
- [ ] 直列接続と並列接続の合成抵抗を求められる。
- [ ] キルヒホッフの第1法則・第2法則から回路方程式を立てられる。
- [ ] 電圧、電流、抵抗、起電力を未知数とする直流回路を解ける。
- [ ] 電力、電力量、ジュール熱を計算できる。

## モデルコアカリキュラムとの対応

| 分野 | 到達目標 |
|------|----------|
| 電流 | オームの法則やキルヒホッフの法則を用いて、電圧、電流、抵抗を求めることができる。 |
| 電流 | 抵抗を直列接続及び並列接続したときの合成抵抗を求めることができる。 |
| 電流 | ジュール熱や電力に関する計算ができる。 |
